## 三、合规边界（本轮与后续均遵守）

- 不做 HTTPS 抓包解密 / 全量流量抓包；仅认证相关调试预览。
- 不做端口 / ARP / 子网扫描；不引入代理、翻墙功能。
- 不新增清单外页面与功能；C++ 核心与 QML 严格分层，UI 改动不破坏认证与探测核心。
- 登出、踢设备等破坏性操作二次确认，默认不误踢本机。
