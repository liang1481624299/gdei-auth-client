2. 问题处置清单

本轮关闭（3 条）

P1-02诊断探测在 QML 直发网络请求并解析响应（分层下沉不足） 改进项 · 耦合已修复

新增 src/app/DiagnosticsController.hpp / .cpp；接线 AppController、main.cpp、CMakeLists.txt；改造 qml/pages/DiagnosticsPage.qml

处置：新增 DiagnosticsController（QObject），暴露 probeHttp() / probeDoh() / sniffCharset() 三个 Q_INVOKABLE 异步接口，经 httpProbeFinished / dohProbeFinished / encodingFinished 信号回传结构化结果。原 QML 内三块 XMLHttpRequest（HTTP HEAD、DoH 并行 GET、门户页编码嗅探）与 charset 正则全部移除；页面改为 Connections 订阅信号回填卡片，文案模板与 i18n 键保留在前端。

后端范式：独立 QNetworkAccessManager，不带认证 CookieJar（公开只读探测与会话隔离）；证书默认严格校验，不跟随「跳过证书校验」开关；每请求 setTransferTimeout（取 max(1000, config.probeTimeoutMs())）；错误归类为 timeout / network / 空串，与原 QML 口径一致。charset 嗅探优先级 Content-Type header → HTML meta charset，嗅不到返回空（不兜底 utf-8，对齐原行为）。

边界：诊断链路不属于登录认证 / 报文解析 / 保活逻辑，本轮未触碰主链路。全项目 QML 已无 XMLHttpRequest 直发请求（命中仅为各对话框 .open()）。关联模块：耦合、后端网络。

P1-03QML 散落门户域名 / 端口 / 公共探测地址（未走常量或配置默认值） 改进项 · 硬编码已修复

src/core/Constants.hpp（新增 4 个诊断常量）；src/app/DiagnosticsController.cpp（常量取值）；qml/pages/DiagnosticsPage.qml（地址字面量移除）

复核：全仓 QML 业务代码（排除 SVG 图标 xmlns / 版权 URL）已无门户域名、端口或公共探测地址字面量。188 行兜底主机带 8080 端口的口径由后端常量统一保留，编码探测目标端口与改动前等价，无行为漂移。关联模块：硬编码、适配。

P2-04兜底密钥存储依赖编译期 pepper，抗逆向能力有限（已知低风险限制）漏洞 · 低风险 · 安全已知限制 · 需人工复核

src/core/secretstore_fallback.cpp:48–50（appPepper 编译期常量）；适用 Linux / Android 兜底后端

影响：PBKDF2-HMAC-SHA256（120k 迭代）+ encrypt-then-MAC 已消除裸 Base64 可逆读取并带篡改校验；但 pepper 随二进制分发，无法抵御逆向工程取钥。Windows / macOS 走系统凭据库，风险面较小。

建议：后续接入 Linux Secret Service / Android Keystore 平台级密钥库；当前实现注释已如实标注能力边界，不作为阻断项。是否在本期内接入平台 Keystore，需人工复核安全优先级与各端工作量。关联模块：硬编码安全。

5. 合规与红线自检

  • 网络边界：诊断 Controller 仅发起公开只读探测（HTTP HEAD、公共 DoH 解析 example.com、门户页 GET 嗅探编码）；未引入代理 / 翻墙、未做端口 / ARP / 子网扫描、未打包浏览器内核 / CEF / WebView。
  • 主链路未改：未改动登录认证、报文解析、保活逻辑；诊断请求与会话 CookieJar 隔离，证书严格校验。
  • 身份与隐私：未自建用户数据库、未缓存全校学生信息；敏感信息运行时拉取不落仓库，日志脱敏口径维持不变。
  • 平台合规：CMake 条件编译（WIN32 / APPLE / ANDROID / UNIX）、Android 权限仅 INTERNET + ACCESS_NETWORK_STATE、Cleartext 域名限定均维持既有基线。
  • i18n：本轮未新增文案键，诊断页复用既有 diagnostics.* / network.* / common.* 键；抽查 httpDetail / netErrorDetail / dohNote / encTarget / encUiFixed 在 zhCN / zhTW / enGB / ja 四语言均存在，占位符 %1 / %2 保留。
  • 构建与回归：全量 configure + build EXIT=0；qmllint 改动文件无 error（仅既有 unqualified 风格警告，并入 P3-03）；运行冒烟进程稳定，stage 日志 controller ready / loaded, rootObjects=1，stderr 无 ReferenceError / TypeError。
