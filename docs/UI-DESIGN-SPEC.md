gdei-connect 终极 UI/UX 交互设计规范
 
（AI 强制约束｜杜绝反人类设计｜分层降噪｜用户心智对齐｜正式交付版）
 
适用项目：gdei-connect 校园网认证保活客户端
技术栈：Qt6 + QML + C++ 跨平台
目标用户：完全不懂网络的普通大学生
核心设计宗旨：禁止技术思维堆叠功能，必须以小白用户直觉优先
重要前提：AI 编码能力强，但无产品设计经验，本文档用于锁死所有交互逻辑、层级、分组、禁忌行为
 
 
 
一、全局顶层设计原则（所有页面强制遵守）
 
1. 三类状态绝对隔离（项目最核心逻辑，禁止合并）
 
所有页面、所有判断、所有文案必须永远区分三套独立数据：
 
1. 网卡物理层状态（本机有没有网、有没有IP、网卡是否正常）
2. 校园网账号会话状态（是否登录、是否被踢、是否过期、设备超限）
3. 外网真实连通状态（能否上网、DNS正常但TCP半残、完全断网）
 
❌ 绝对禁止
 
- 禁止用“网卡在线”判定“可以上网”
- 禁止用“外网通”判定“账号有效”
- 禁止三种状态混为一个指示灯、一条文案
- 禁止出现：保活中 + 账号不可用 这种矛盾 UI
 
✅ 强制要求
 
首页必须三个独立状态卡片，各自带独立解释文案。
 
 
 
2. 信息层级铁律（AI 最容易犯的错）
 
四层严格分层（从上到下）
 
1. 核心状态层（用户第一眼必须看到：是否能上网、是否登录）
2. 快捷操作层（常用按钮：诊断、刷新）
3. 数据展示层（IP、设备、流量）
4. 底层调试层（子网、MAC、超时参数、底层接口名）
 
❌ 绝对禁止
 
- 禁止把调试参数、技术参数、底层网络信息默认展开给用户看
- 禁止把高危按钮、高级设置、技术配置放到首页显眼位置
- 禁止所有参数平铺排列（AI最爱乱平铺）
 
✅ 强制规则
 
普通用户视图默认干净、极简；技术细节全部折叠。
 
 
 
3. 操作风险分级（严格隔离）
 
普通操作（绿色/蓝色）
 
刷新、测试连通、切换外观、查看日志
 
警告操作（黄色）
 
修改网络参数、更改编码、调整保活间隔
 
高危不可逆操作（红色+二次弹窗）
 
账号下线、注销本地配置、重置默认参数、开启证书跳过
 
❌ 绝对禁止
 
- 禁止高危按钮和普通按钮放在同一行、同一区域
- 禁止无弹窗二次确认
- 禁止红色按钮乱放
 
 
 
4. 全局色彩规范（固定死，不许AI自定义）
 
- 绿色 #10B981：完全正常、在线、连通
- 黄色 #F59E0B：半残网络、会话失效、需要注意
- 红色 #EF4444：断网、错误、失败、被踢下线
- 蓝色 #3B82F6：加载中、探测中、刷新中
- 灰色 #9CA3AF：调试信息、次要文字、折叠内容
 
新增独有状态（解决 AX201 半残网络）
 
- 琥珀警告态：DNS正常、TCP吞吐异常（半连通）
 
 
 
5. 字体与编码乱码根治（跨平台致命问题）
 
✅ 强制
 
1. 程序内置 Noto Sans SC 中文字体，打包嵌入
2. 禁止依赖系统字体（Windows/macOS/Linux/Android 字体不统一会乱码、缺字、方框）
3. UI层、日志层、文件层永远固定 UTF-8
4. 网络解码层单独一套逻辑：自动嗅探 GBK/UTF-8，不污染 UI
 
❌ 绝对禁止
 
- 禁止 UI 语言 i18n 切换影响网络编码解析
- 禁止门户原始编码直接渲染进UI（必须统一转UTF8再渲染）
- 禁止出现任何方框、乱码、问号字符
 
 
 
6. 控件图标严格区分（AI经常混淆）
 
必须两套图标，不许混用
 
1. 页面跳转箭头：进入子页面用
2. 下拉选择箭头：参数下拉用
 
❌ 禁止
 
同一图标表达两种行为，导致用户不知道点下去是弹窗还是新页面
 
 
 
二、全局页面结构（固定 4 Tab，永久不许改）
 
1. 概览（首页）：状态 + 快捷诊断
2. 设备管理：本地配置 + 校园网在线设备
3. 仪表盘：用户数据、余额、套餐、在线时长
4. 设置：偏好、高级参数、日志、事件
 
❌ 禁止
 
- 禁止使用“我的”这种模糊命名
- 禁止业务数据和设置混在一页
- 禁止页面职责模糊不清
 
 
 
三、逐页超详细 UI/UX 强制规范（AI 必看）
 
【1】概览页（首页｜用户第一眼页面）
 
页面唯一定位：快速看状态、快速排错
 
必须包含模块（严格顺序）
 
1. 三大状态独立卡片
- 本机网卡状态
- 校园账号会话状态
- 外网连通状态（含半残网络检测）
2. 保活总开关（最核心功能）
- 文案：自动保活（掉线自动重登）
- 绿色安全区域
3. 快捷功能区
- 刷新网络状态
- 一键网络诊断
4. 最近告警事件（轻量展示）
- 无事件：显示「暂无网络异常事件」
- 有事件：显示最新一条 + 红点角标
5. 网络信息卡片（默认精简）
- 默认只展示：本机局域网IP、校园出口IP
- 底层参数全部折叠在「查看详情」内
 
重点强制逻辑（解决 NAT 宿舍路由问题）
 
双IP严格拆分
 
1. 本机局域网IP
- 小字说明：仅代表本地路由内网，非校园网IP
2. 校园认证出口IP
- 小字说明：学校网关识别的上网IP
 
折叠隐藏内容（默认不显示）
 
- 子网掩码
- 网卡底层设备名（ethernet_xxxx）
- 目标MAC（NAT环境提示：路由环境无法获取）
- 网关地址
 
❌ 首页绝对禁止
 
1. 禁止首页放红色下线高危按钮（极其反人类）
2. 禁止首页堆叠大量技术参数
3. 禁止状态文案冲突
4. 禁止无占位空白
5. 禁止无加载动画
 
 
 
【2】设备管理页（最容易设计混乱）
 
页面强制二分分组（必须完全隔离）
 
分组1：本地认证配置（保活使用的本地账号）
 
- 添加配置
- 保存的账号列表
- 默认配置标记
 
分组2：校园网在线设备（学校服务器数据）
 
- 在线设备列表
- 历史登录设备
- 可下线设备高亮可操作
- 不可操作设备置灰只读
 
✅ 强制文案区分
 
- 本地配置：保活程序使用的本机账号数据
- 在线设备：校园网后台当前登录设备
 
❌ 禁止
 
1. 禁止本地配置和云端设备混为一页列表
2. 禁止所有设备全部可下线（必须区分权限）
3. 禁止缺少分组标题
4. 禁止信息高密度堆叠
 
 
 
【3】仪表盘页（用户数据中心）
 
页面定位：只展示用户业务数据，不存放任何设置
 
必须模块：
 
1. 账号状态卡片（正常/封禁/会话失效/设备超限）
2. 账户余额（带刷新、带失败提示）
3. 套餐流量信息
4. 本次在线时长
 
两个按钮严格隔离、视觉区分
 
1. 下线账号（退出校园网会话，保留本地账号）
2. 注销配置（删除本地账号凭证，彻底清空）
 
❌ 禁止
 
1. 禁止两个按钮样式相近
2. 禁止数据加载失败只写“暂无法获取”
3. 禁止无重试按钮
4. 禁止设置项混入仪表盘
 
 
 
【4】设置页面（所有配置统一收纳）
 
固定分组（必须分组平铺，禁止乱排）
 
1. 基础偏好设置
- 语言切换
- 外观主题
2. 系统工具
- 高级设置（子页面）
- 事件记录
- 系统日志
- 关于软件
 
强制细节
 
- 事件记录有未读红点角标
- 所有跳转子页面统一箭头
- 所有下拉设置统一下拉图标
 
 
 
【5】高级设置页面（AI 最大重灾区｜专治乱平铺）
 
强制 4 大折叠分组（默认全部折叠）
 
分组1：编码与安全（高危组）
 
- 发包编码：自动探测（默认）、UTF8、GBK
- 跳过证书校验（红色警告+风险文字）
 
分组2：保活策略
 
- 最小保活间隔
- 最大保活间隔
- 离线判定次数
 
分组3：超时参数
 
- 连接超时
- 探测超时
 
分组4：探测地址配置
 
- 外网连通探测地址
- 校园账号会话探测地址
 
强制校验规则（AI绝对想不到的逻辑）
 
1. 最小保活间隔 必须小于 最大保活间隔
2. 所有时间参数 禁止0、禁止负数
3. 所有URL必须合法URL校验
4. 参数修改不合法直接拦截、弹窗提示
5. 底部必须有：重置默认配置按钮
 
强制文案
 
每个参数必须带有小字解释，让学生看得懂
 
❌ 绝对禁止
 
1. 禁止所有参数平铺不分组
2. 禁止高危选项和普通参数混排
3. 禁止无校验、无拦截、无重置
4. 禁止去掉「自动编码探测」
 
 
 
四、反人类 UI 黑名单（AI 永久禁止行为）
 
1. 禁止功能堆叠
 
2. 禁止无分组平铺列表
 
3. 禁止技术参数默认展开
 
4. 禁止高危操作无隔离无弹窗
 
5. 禁止三种网络状态逻辑混用
 
6. 禁止双语义图标混用
 
7. 禁止页面职责混乱（设置和数据混页）
 
8. 禁止系统字体依赖（乱码根源）
 
9. 禁止网络编码与UI语言互相干扰
 
10. 禁止 NAT 环境错误展示校园内网段误导用户
 
11. 禁止半残网络无对应状态提示
 
12. 禁止加载空白、无占位、无loading
 
13. 禁止失败文案无原因、无重试
 
14. 禁止按钮语义模糊（下线/注销分不清）
 
 
 
五、最终验收标准（100%交付标准）
 
视觉层面
 
- 界面干净、分层清晰、无杂乱信息
- 所有状态颜色统一规范
- 跨平台字体统一、无乱码、无方框
- 自适应横竖屏、高DPI
 
交互层面
 
- 小白用户不点错、不迷惑、不误解
- 高危操作全部二次确认
- 所有错误有原因、有重试、有说明
- 所有技术细节默认折叠
 
逻辑层面
 
- 三层网络状态完全隔离
- 本地/云端设备完全隔离
- 设置/数据页面完全隔离
- 编码/UI语言完全隔离
- 参数全部强校验，无非法配置写入
 
 
 
六、极简一句话给 AI 总结（开发总纲）
 
所有界面：小白优先、极简优先、分层优先、隔离优先、降噪优先。
禁止开发者思维堆叠参数、禁止平铺乱排、禁止语义冲突、禁止状态混乱。
