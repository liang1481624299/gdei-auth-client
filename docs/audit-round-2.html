影响：网络请求、超时与响应解析落在 QML，违反「C++ 管网络 / 解析，QML 只渲染交互」；QML 侧 XHR 与后端 QNAM 的 CookieJar / SSL 配置 / 超时口径不一致，移动端网络栈行为难以统一与测试。

遗留原因（卡点）：下沉需新增 C++ 诊断 Controller（QObject），暴露 probeHttp(url) / probeDoh(endpoints) / sniffCharset(host) 异步接口并经信号回传结构化结果，页面改为订阅渲染；属网络层结构性重构，本轮按「改动最小必要、不新增无关功能」未强行落地。诊断链路不属于登录认证 / 报文解析 / 保活逻辑，下轮可在不触碰认证主链路的前提下单独实施。

建议：下轮先出 Controller 接口与异步回传协议设计，再迁移 HTTP / DoH / 编码嗅探三类探测；QML 仅保留结果渲染与交互。关联模块：耦合、后端网络。

7. 结论

总体评价：本轮在不动认证 / 解析 / 保活主链路的前提下，清掉了全部可安全落地的死代码与注释欠账，收敛了一处前端默认主机硬编码，并澄清了一处 i18n 误报。工程基线保持良好：主题令牌完整、网络超时 / SSL / 退避齐全、门面分层清晰、平台与权限合规、凭证非明文。

Top 3 事项：
