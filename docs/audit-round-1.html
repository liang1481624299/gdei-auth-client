3. 问题清单（按等级分组）

P0 阻断 / 高危（0 条）

未发现明文凭证、认证绕过、硬编码致多端不可用、循环绑定崩溃或安全校验缺失直连。SSL 校验默认严格，仅用户显式开启不安全开关时放行并写警告日志；口令经 PBKDF2 + encrypt-then-MAC 加密落盘，未见硬编码 Token / 私钥。

P1 明显缺陷（4 条）

P1-01死代码：未引用页面与组件仍进资源 / 游离磁盘 改进项 · 复用遗留

qml/pages/DashboardPage.qml（436 行，未登记 qrc、无引用）；qml/pages/SettingsPage.qml（69 行，未登记 qrc、无引用）；qml/components/LocalDeviceCard.qml（182 行，CMakeLists.txt:194 已登记 qrc、无引用）；qml/components/BaseChart.qml（142 行，CMakeLists.txt:172 已登记 qrc、无引用）

影响：已登记 qrc 的死组件仍被打包进产物，增大体积；游离页面与旧卡片误导维护者，难以判断哪套是现行实现。

建议：确认无字符串名 / 动态加载引用后，从 CMake qrc 清单与磁盘移除；如需保留历史参考，迁移至 docs/legacy 且不进 qrc。关联模块：复用。

P1-02诊断探测在 QML 直发网络请求并解析响应（分层下沉不足） 改进项 · 耦合遗留

qml/pages/DiagnosticsPage.qml:101（HTTP HEAD 探测）、146（DoH 并行 GET）、190（门户页编码嗅探）；正则解析 charset 见 201–206 行

影响：网络请求、超时与响应解析落在 QML，违反「C++ 管网络 / 解析，QML 只渲染交互」的分层；QML 侧 XHR 与后端 QNAM 的 CookieJar / SSL 配置 / 超时口径不一致，移动端网络栈行为难以统一与测试。

建议：新增诊断 Controller（C++ QObject），暴露 probeHttp(url)、probeDoh(endpoints)、sniffCharset(host) 异步接口，经信号回传结构化结果；页面只订阅结果渲染。本轮先标注，下沉改动涉及网络层，需单独评估。关联模块：耦合、后端网络。

P1-03QML 散落门户域名 / 端口 / 公共探测地址（未走常量或配置默认值） 改进项 · 硬编码遗留

qml/pages/DiagnosticsPage.qml:100 https://www.baidu.com；140–141 AliDNS / Cloudflare DoH 端点；188 nac.gdei.edu.cn:8080；qml/components/LocalDeviceEditor.qml:14 defaultHost = "nac.gdei.edu.cn:8080"

影响：门户主机 / 端口在 QML 重复硬编码，与 Constants.hpp 的默认主机口径可能漂移；更换探测目标或门户地址时需改多处 QML。

建议：默认主机/端口由后端 Constants 经 AppController 或 app.config 暴露给 QML；DoH / 探测兜底地址收敛为可配置常量或后端模型。关联模块：硬编码、适配。

P1-04i18n 四语言缺口：诊断页部分键缺译 / 字典缺失 改进项 · 适配 / i18n遗留

src/core/I18n.cpp；引用方 qml/pages/DiagnosticsPage.qml

缺口明细：字典整体缺失 diagnostics.speedTitle、diagnostics.speedDesc；zhTW 缺 offloadTitle/offloadDesc/traceDesc（3）；enGB 缺 dotTitle/dotDesc/offloadTitle/offloadDesc/traceTitle/traceDesc（6）；ja 缺 dotTitle/dotDesc/offloadTitle/offloadDesc/traceTitle/traceDesc 及 logDone/logDoneDetail/logFail（9）。

影响：缺译键在对应语言下回退裸键名或英文，界面中英文混杂。

建议：按既有四语言表补齐上述键译文；"2d" 为 Canvas getContext("2d") 误报，忽略。关联模块：适配。

P2 优化项（5 条）

P2-01图表网格线颜色绕过 Theme 令牌硬编码改进项 · 样式遗留

qml/components/BaseChart.qml:73 Qt.rgba(0.133,0.149,0.188,0.6)（注释对应 #222630 a0.6）

影响：网格线颜色未走 th.gridLine，深浅色切换或令牌调整时图表不同步。

建议：改用 th.fill(th.gridLine, 0.6) 派生。关联模块：样式。

P2-02Accept-Language 请求头写死英文，未随 locale改进项 · 硬编码 / 适配遗留

src/core/Constants.hpp:96 ACCEPT_LANGUAGE = "en-US,en;q=0.9"

影响：门户过滤器要求该头存在（保留是必要的），但语言优先级固定英文；非英文 locale 下可按当前语言补充偏好。

建议：在请求组装处按 i18n 当前语言派生 Accept-Language，常量保留英文兜底。关联模块：硬编码、适配。

P2-03巨型页面 / 组件，内聚度偏高改进项 · 复用遗留

qml/pages/MinePage.qml（447 行）；qml/pages/AdvancedSettingsPage.qml（435 行）；qml/components/NetworkInfoCard.qml（322 行）

影响：单文件承载多组表单 / 卡片 / 状态分支，维护与复查成本上升。

建议：按分组抽为子组件（账号卡、偏好分组、链路明细行等），页面只做编排。关联模块：复用。

P2-04兜底密钥存储依赖编译期 pepper，抗逆向能力有限（已知低风险限制）漏洞 · 低风险 · 安全已知限制

src/core/secretstore_fallback.cpp:48–50（appPepper 编译期常量）；适用 Linux / Android 兜底后端

影响：PBKDF2-HMAC-SHA256（120k 迭代）+ encrypt-then-MAC 已消除裸 Base64 可逆读取并带篡改校验；但 pepper 随二进制分发，无法抵御逆向工程取钥。Windows / macOS 走系统凭据库，风险面较小。

建议：后续接入 Linux Secret Service / Android Keystore 平台级密钥库；当前实现注释已如实标注能力边界，不作为阻断项。关联模块：硬编码安全。

P2-05新旧设备卡片组件结构重叠，旧实现未随新卡片下线改进项 · 复用遗留

qml/components/LocalDeviceCard.qml 与 DeviceCard.qml / DeviceItem.qml 字段与操作行结构相近

影响：同一类设备信息存在两套渲染结构，样式调整需双处同步。

建议：在 P1-01 清理死代码时确认新旧边界，统一到 DeviceCard，删除冗余旧卡片。关联模块：复用。

P3 轻微（3 条）

P3-01后端排障日志为双语硬编码串，未走 i18n改进项 · i18n / 日志遗留（历史决策保留）

src/core/KeepAlive.cpp、PortalClient.cpp、DevicePortalClient.cpp 中 "English / 中文" 双语 log 串

影响：这些串同时进入日志面板与落盘文件，便于排障；未纳入 i18n 字典。属既有刻意保留，非界面文案。

建议：维持现状；若后续要求日志多语言，再单独抽取日志文案键。关联模块：适配。

P3-02组件头注释残留旧色值 / 圆角描述，与令牌现状滞后改进项 · 可读性遗留

qml/components/BaseCard.qml:7、BaseTextField.qml:8、BaseChart.qml:6 头部注释中的 #111318 / #272A33 / 8 圆角等

影响：注释描述与 Theme 令牌实际值不完全一致，易误导。

建议：更新注释为引用令牌名（card / border / radiusCard），不再写死色值。关联模块：样式。

P3-03qmllint 全局 Unqualified access 风格警告改进项 · 规范遗留

全部 QML 中 app.* 全局单例未限定访问

影响：qmllint 报 unqualified 警告；不影响运行，但长期不利于组件隔离检查。

建议：长期评估引入 pragma ComponentBehavior: Bound 并逐步限定外部 ID 访问；本轮不强制改写全项目风格。关联模块：复用。
