0. 审计结论摘要

项目整体分层清晰、core 未反向依赖 app/platform，QML 未做文件/网络 IO，事件由 C++ 单向下发；但在核心保活状态机、跨平台凭据安全、i18n 双语串绕过、高分辨率适配收口四处存在阻断级缺陷。文档宣称能力（CAS/NAC 账户中心、RPM/Arch 包、Android 交付）与实现存在系统性漂移。

最高风险（P0-01）：KeepAlive::onOnlineChanged 依赖 onlineChanged 信号累加失败次数，而该信号仅在值翻转时发出。首次掉线后 online 已为 false，后续探测失败不再触发信号，m_failCount 永远停在 1，默认阈值 3 不可达 —— 断线自动重登实质失效，保活只剩探测、没有恢复动作。
正向结论：① 全部 QML app.* 调用均有 C++ 定义，悬空请求为空集；② 无跨层逆向依赖、无 QML 伪造业务事件；③ 网络 reply 均 deleteLater()、QTimer 显式 stop()，无显著资源泄漏；④ 四语言词条 key 集合完全对齐，缺失 key 为空集；⑤ QML UI 文案零硬编码中文。

2.2 鉴权、越权与返回码

  • 鉴权链路：本地登录态 session.loggedIn 仅为 UI 门禁（Main.qml:28-40 双 Loader 互斥），并非服务端鉴权；服务端会话由 SessionCookieJar 内存态持有，重启即失效 —— 设计合理，但 route() 属性提供第二套路由语义且未被使用，埋绕过隐患（P1-22）。
  • 越权风险：probeUrl/healthUrl 无 scheme/host 白名单（P1-06）；AndroidManifest 明文流量（P0-03）；自助门户 Cookie 手工拼进 URL path（P1-35）。
  • 返回码语义：PortalClient.cpp:426 将 status==0 视为 HTTP 成功并凭响应体特征串判在线；onLogoutReply 不检查 reply->error() —— 服务端未真正下线也会本地显示下线（P1-01）。
  • 重复定义：login/logout 在 AuthController、SessionController、PortalClient 三处；refreshStatus 两处；门面层 DeviceController/LogController 为纯转发（P1-31）。

2.3 接口文档与前端调用比对

前端悬空请求：空集。已逐一核对 session.login/logout、auth.startKeepAlive/stopKeepAlive、localDevices.*、network.refresh、config.save、logs.exportLog、events.*、portalDevices.*、i18n.setLang/text 全部有 C++ 定义；信号 onToastRequested/onEntriesChanged/onLastErrorChanged 均有对应 C++ signal。

5. i18n 国际化专项

项目结论
支持语种ZhCN / ZhTW / EnGB / Ja（4 种），默认 ZhCN
词条规模每语种 211 条，共 844 条；四语言 key 集合结构对齐

关键风险

  • 语种不可切换（P0-04）：PortalClient.cpp:287,352,389,407、DevicePortalClient.cpp:225,264,277,343,391,423、KeepAlive.cpp:35-87 使用 tr() 中英合体串；AuthController.cpp:12-20 的 localizedMessage() 仅翻译 3 个 encoding.* key，其余原样返回 —— 中文用户看到中英混杂，切换语言无效。
  • 快照式翻译（P1-15/16）：ToastHost.qml:37-49 在收到事件时把译文存入 ListModel（存字符串非 key），切语言后队列内 toast 不变；LoginPage.qml:183 取 session.lastError，SessionController 未连接 langChanged。
  • 文本拼接（P1-17）：LocalDeviceCard.qml:163,171 用 localized("label.username") + ": " + value，冒号位置固定，破坏 RTL/中文语序；TrayController.cpp:101-102 拼接两段译文 + 硬编码 " — "。
  • 参数化不完整：I18n::text(key) 不支持参数，ToastHost/EventListItem 各自手写 .arg(args.name) 且仅替换第一个 %1；KeepAlive.cpp:81 的 %1/%2 词条无法在 UI 正确填充。
  • 本地化缺失（P1-18）：全库无 QLocale；EventListItem.qml:58 硬编码 yyyy-MM-dd HH:mm:ss，Logger.cpp:128 手写 HH:mm:ss，Logger.cpp:87 日志等级英文缩写直显。
  • key 规范：btn.* 与 action.* 混用、login.success 与 auth.loginSuccess 双份表达、devices.* 与 profiles.* 边界模糊。

6.3 滚动 / 触控

  • 完整实现：LoginPage、PageScaffold（所有二级页）、AppDialog、LocalDeviceEditor、EventLogPage、LogPanel、DevicePanel 均有 ScrollView/ListView + WheelHandler + ScrollBar（滚轮步长已统一 th.wheelStep）。
